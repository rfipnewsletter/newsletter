# RFIP Newsletter · Issue 01

An editorial web newsletter for **Vision for Rwanda, Window to the Continent**.

## Preview locally

With Node.js installed, run:

```sh
node serve-local.cjs
```

Then open [http://localhost:8000](http://localhost:8000).

## Project files

- `index.html` — newsletter page and responsive styling
- `assets/` — RFIP artwork and image assets used by the page
- `RFIP_Newsletter_Design_Handoff.md` — design direction, asset notes, and items to confirm before release
- `newsletter_source.html` and `newsletter_source.original.html` — source newsletter files retained from the working project

Some photos are illustrative placeholders. See the handoff notes before publishing.
